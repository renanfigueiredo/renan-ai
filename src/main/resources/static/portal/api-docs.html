Fluxo Assíncrono

A API usa um padrão de polling assíncrono para evitar timeouts. Respostas longas (como estudos bíblicos) podem levar 30–60s para gerar.

1
POST /api/v1/chat
Envia o prompt · retorna id em ~50ms
2
status: PROCESSING
IA gerando resposta via streaming
3
GET /api/v1/chat/{id}
Polling até status: COMPLETED
4
result: "..."
Texto completo da resposta

Recomendação: faça polling a cada 3–5 segundos. Respostas simples chegam em ~5s. Estudos bíblicos completos podem levar até 60s.

Endpoints

A API expõe 2 endpoints de chat.

POST /api/v1/chat Criar tarefa de chat
Request Body — application/json
CampoTipoObrigatórioDescrição
prompt string ✓ Sim Pergunta ou instrução para a EVJ AI. Máx: 50.000 caracteres.
Response — 202 Accepted
CampoTipoDescrição
id string ID único da tarefa. Ex: chat-a1b2c3d4
status string PROCESSING · COMPLETED · FAILED
prompt string O prompt enviado (espelhado).
result string | null Resposta da IA. Disponível quando status: COMPLETED.
error string | null Mensagem de erro. Disponível quando status: FAILED.
createdAt string (ISO 8601) Timestamp de criação da tarefa.
completedAt string | null Timestamp de conclusão. Disponível quando concluído.
Status Codes
202
Tarefa criada com sucesso. Consulte o ID retornado.
400
Prompt inválido, ausente ou excede o limite de caracteres.

Mesmo schema do POST. O campo status indica o andamento. Quando COMPLETED, o campo result contém a resposta em Markdown.

Exemplos de Código

Exemplos completos com polling automático em várias linguagens.

cURL

bash 
# 1. Enviar prompt
ID=$(curl -s -X POST https://evj.app.br/api/v1/chat \
  -H "Content-Type: application/json" \
  -d '{"prompt": "Explique o Sermão do Monte em Mateus 5"}' \
  | grep -o '"id":"[^"]*"' | cut -d'"' -f4)

echo "Task ID: $ID"

# 2. Polling até completar
while true; do
  RESPONSE=$(curl -s "https://evj.app.br/api/v1/chat/$ID")
  STATUS=$(echo $RESPONSE | grep -o '"status":"[^"]*"' | cut -d'"' -f4)

  echo "Status: $STATUS"

  if [ "$STATUS" = "COMPLETED" ]; then
    echo $RESPONSE | python3 -c "import json,sys; d=json.load(sys.stdin); print(d['result'])"
    break
  elif [ "$STATUS" = "FAILED" ]; then
    echo "Falhou: $RESPONSE"
    break
  fi

  sleep 3
done

JavaScript (fetch)

javascript 
async function askEvjAI(prompt) {
  const BASE = 'https://evj.app.br';

  // 1. Criar tarefa
  const postRes = await fetch(`${BASE}/api/v1/chat`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ prompt })
  });
  const { id } = await postRes.json();
  console.log('Task criada:', id);

  // 2. Polling até completar
  while (true) {
    await new Promise(r => setTimeout(r, 3000)); // aguarda 3s

    const pollRes = await fetch(`${BASE}/api/v1/chat/${id}`);
    const task = await pollRes.json();

    console.log('Status:', task.status);

    if (task.status === 'COMPLETED') return task.result;
    if (task.status === 'FAILED')    throw new Error(task.error);
  }
}

// Uso
askEvjAI('Quais são as bem-aventuranças de Mateus 5?')
  .then(result => console.log('Resposta:', result))
  .catch(err   => console.error('Erro:', err));

Python

python 
import requests
import time

BASE_URL = "https://evj.app.br"

def ask_evj_ai(prompt: str) -> str:
    # 1. Criar tarefa
    res = requests.post(
        f"{BASE_URL}/api/v1/chat",
        json={"prompt": prompt}
    )
    res.raise_for_status()
    task_id = res.json()["id"]
    print(f"Task criada: {task_id}")

    # 2. Polling até completar
    while True:
        time.sleep(3)
        poll = requests.get(f"{BASE_URL}/api/v1/chat/{task_id}")
        task = poll.json()
        print(f"Status: {task['status']}")

        if task["status"] == "COMPLETED":
            return task["result"]
        elif task["status"] == "FAILED":
            raise RuntimeError(task.get("error", "Falha desconhecida"))

# Uso
if __name__ == "__main__":
    resposta = ask_evj_ai("O que a Bíblia diz sobre oração?")
    print("Resposta:", resposta)
